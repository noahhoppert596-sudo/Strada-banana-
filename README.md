# Strada Banana – Beach Bar Koh Phangan

Demo-Website einer fiktiven Strandbar in Thailand (Koh Phangan).

- Lade-Screen + Entsperr-Intro mit Code-Tastenfeld
- Realistischer 3D-Cocktail (Three.js), der sich beim Scrollen füllt, während die Sonne untergeht
- Karte mit Test-Warenkorb und Checkout (keine echte Zahlung)
- Fotos: Unsplash (Unsplash-Lizenz)

Live: https://noahhoppert596-sudo.github.io/Strada-banana-/
